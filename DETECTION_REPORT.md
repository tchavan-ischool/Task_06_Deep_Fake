# Synthetic Media Detection Report

## Artifact

ElevenLabs Version 1

## Known Ground Truth

The recording was completely AI-generated using ElevenLabs.

## Detection Result

- Detection Tool: AI Voice Detector
- AI Score: 16%
- Verdict: Likely Human
- Segments analyzed: 19
- Maximum AI score: 50%

## Interpretation

The detector produced a false negative.

Although the artifact was completely synthetic, the system classified it as
likely human.

This experiment demonstrates that automated detection should not be treated as
definitive evidence of authenticity.

Provenance documentation provides stronger evidence of the artifact's origin
because the generation process, tool, script, iterations, and output files are
documented directly in this repository.
